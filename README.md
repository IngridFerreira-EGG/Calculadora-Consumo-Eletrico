Este sistema em ![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white) foi desenvolvido com o objetivo de calcular o consumo médio mensal de energia elétrica de qualquer aparelho eletrodoméstico, permitindo estimar tanto o consumo em kWh quanto o gasto financeiro (em R$) na conta de luz.
![Calculadora](https://img.shields.io/badge/Projeto-Calculadora-blue?style=flat-square) O cálculo é feito utilizando a seguinte fórmula matemática para encontrar o consumo em Quilowatts-hora (kWh):

$$Consumo (kWh) = \frac{Potência (W) \times Horas por dia \times Dias no mês}{1000}$$

$Gasto (reais) = {Consumo (kWh) \times Preco}$
